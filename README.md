# Random Data Generator

Realistic sample CSVs — up to 10 million rows.

**Live:** https://randomdata.useful-indeed.com

Random Data Generator creates realistic sample data as a CSV file, right in your browser. It's made for testing spreadsheets, databases, dashboards and apps without touching real customer data. Pick your columns and data types, set rules like Unique, Required and Key, choose how clean or messy the data should be, preview it and download up to 10,000,000 rows.

## How to use

1. Name your columns and choose a data type for each (names, emails, dates, amounts, companies and more).
2. Set rules: Unique, Required or Key, plus how many rows you need.
3. Choose the data quality — perfectly clean, or realistically messy with blanks, typos and duplicates.
4. Check the summary, preview the first rows and download your CSV.

## Privacy

Everything runs in your browser. Nothing is stored. The data you generate goes straight to your download.

## Updating the data lists

The value lists live in `data/` (one item per line). If you add a new `.txt` file, also add its name to `data/manifest.json`.
